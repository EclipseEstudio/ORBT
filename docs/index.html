Como instalar?
  1. Baixe e abra o APK no Android.
  2. Se solicitado, permita instalar apps desta fonte.
  3. Toque em Instalar ou Atualizar. Depois, desative essa permissão.

Atualizar ou reinstalar

Para manter seu progresso, abra o APK novo sobre o ORBT já instalado. Reinstalar a mesma versão compatível também mantém os dados; desinstalar o aplicativo pode apagar progresso e configurações.

Se o Android informar conflito de pacote ou assinatura, interrompa a instalação. Algumas versões antigas de teste usavam chaves temporárias e podem exigir uma reinstalação única para migrar para a assinatura permanente. Não desinstale para resolver isso sem considerar a perda dos dados.
