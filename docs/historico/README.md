# Arquivo histórico

Aqui ficam relatórios de implementação, testes e decisões produzidos durante o desenvolvimento. **Não são a especificação atual.** Data, revisão, ambiente e limites do relatório determinam o que cada evidência comprova.

| Pasta | Uso |
| --- | --- |
| `registros/` | Relatórios de validação, balanceamento, revisões de issues e snapshots de planejamento |
| `evidencias/` | Capturas, medições e anexos dos relatórios |

- [Validação técnica de 10/11/2026](registros/validacao-2026-11-10.md): suítes, pacote, renderização, editor, Web e limites do teste Android.

- [Registro de campanha de 30 fases](registros/campanha-30-fases.md).

Os textos podem mencionar regras substituídas, branches, APKs ou artefatos já indisponíveis. Números de verificações são históricos. Relatórios não atualizam automaticamente o status das issues. A guia atual de mira, por exemplo, é reta; medições de previsão gravitacional antiga não medem essa implementação.

Fontes/prompts de arte ficam em [arte](../arte/README.md), pois ainda podem ser usados para regenerar recursos. Notas de release ficam em [versões](../versoes/README.md). Para trabalhar no jogo, use a [documentação atual](../README.md).
