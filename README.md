# ORBT

ORBT é um jogo de puzzle espacial desenvolvido em Godot. O jogador controla uma nave por impulsos, administra o combustível e usa a gravidade dos corpos celestes para alcançar seu destino.

## Organização do repositório

A branch `main` contém este README e a página de download publicada pelo GitHub Pages.

- [Jogar no Android — página de download](https://eclipseestudio.github.io/ORBT/)
- [Como publicar novas versões do APK](docs/tecnica/publicacao-web.md)

- [Branch alpha](https://github.com/EclipseEstudio/ORBT/tree/alpha): código e documentação de desenvolvimento.
- [Código anteriormente integrado à main](https://github.com/EclipseEstudio/ORBT/tree/codex/backup-main-2026-10-29): cópia integral preservada antes da organização de 29/10/2026, incluindo recursos, editor de fases, testes e instruções de execução.
